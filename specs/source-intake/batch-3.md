# Batch three salmon datasets

This batch adds 30 publisher records. The tables below link each local intake recipe to the original record. Some recipes cover a whole deposit, while others select a particular survey, year, worksheet or set of fields. Each recipe describes its selection and identifies the files needed to reproduce it.

The 49 tables contain 134,383 source records, including detections, samples, surveys, estimates, summaries and lookups. The same fish can appear in multiple detection records. The [replay instructions](README.md) explain how to rebuild the packages and find the tables in the local graph.
