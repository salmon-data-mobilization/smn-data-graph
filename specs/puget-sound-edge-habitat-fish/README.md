# Juvenile salmonid use of Snoqualmie and Green River margins

King County sampled fish along six edge habitat types in the Snoqualmie and Green rivers from 2016 through 2022. This intake covers the complete electrofishing table, including survey notes. The separate physical habitat table remains available in the deposit.

Aaron David, Christopher Gregersen, Joshua Kubo, Daniel Lantz, James Bower published version 1 under CC0. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.24539695.v1) · [Version metadata](https://api.figshare.com/v2/articles/24539695/versions/1) · [License](https://creativecommons.org/publicdomain/zero/1.0/)

The selected source contains 9,829 rows and 17 selected fields. The package adds a one-based row number for source lookup. The 30 cells with edge whitespace have their original strings indexed by field position for exact reconstruction. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
