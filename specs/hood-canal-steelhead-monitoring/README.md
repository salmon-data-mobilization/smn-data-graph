# Hood Canal steelhead monitoring sample records

The study followed six Hood Canal steelhead populations during a supplementation assessment. The package covers every data row and eight original columns on Sheet1 (A, C, D, E, F, G, I, J): fish ID, brood year field BY, supplementation stage, method, river, reach, fork length and weight. Formula-derived columns, genetics and other workbook fields remain in the original.

The authors credit people from the Skokomish Tribal Nation, Hood Canal Salmon Enhancement Group, Long Live the Kings, NOAA Fisheries and Washington Department of Fish and Wildlife for work on sampling, data collection and fish rearing. The Nation also supported the project. [Study funding and acknowledgments](https://doi.org/10.1371/journal.pone.0339458)

The selected source contains 10,882 rows and 8 selected fields. The package adds a one-based row number for source lookup. Excel numeric cells retain their stored numeric text. The verifier independently compares worksheet values using an Excel reader. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
