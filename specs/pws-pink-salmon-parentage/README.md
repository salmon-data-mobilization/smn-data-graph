# Parentage assignments of Prince William Sound pink salmon

Four files give parentage assignment results for pink salmon collected at Stockdale Creek and Hogan Bay Creek. Each creek has a file for the 2013–2015 lineage and one for 2014–2016. [KNB dataset](https://knb.ecoinformatics.org/view/doi:10.5063/F1DR2SWP)

| Package table | Records | Original fields | Local record key |
| --- | ---: | ---: | --- |
| stockdale_paired_14_16_filter_parents | 794 | 17 | franz_id |
| stockdale_paired_13_15_filter_parents | 974 | 17 | franz_id |
| hogan_paired_14_16_filter_parents | 651 | 17 | franz_id |
| hogan_paired_13_15_filter_parents | 763 | 17 | franz_id |

The four parent-generation tables retain their original sample identifiers, otolith marks and parentage results. The archive separately contains pedigree software inputs and sample location information. The study estimates relative reproductive success from incomplete pedigrees.
