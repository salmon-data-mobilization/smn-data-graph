# Methow River floodplain fish biomass and production

The Methow River food-web study compared fish abundance, biomass and production across sampling sites and study years. This package covers the complete fish biomass and production worksheet, including species alongside salmon and steelhead. Repeated 95% interval headers retain their original column positions. The two diet and invertebrate workbooks remain in the deposit.

The study credits staff of the US Bureau of Reclamation and the Methow River Salmon Recovery Foundation for project design, fish field sampling and data delivery. The Bureau funded the study. [Study acknowledgments](https://doi.org/10.1002/eap.3076)

The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. The selected source contains 52 rows and 12 selected fields. The package adds a one-based row number for source lookup. Unnamed or repeated headers receive positional aliases. Original column labels and order remain traceable to the pinned file. Excel numeric cells retain their stored numeric text. The verifier independently compares worksheet values using an Excel reader. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
