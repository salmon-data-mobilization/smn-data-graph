# California Chinook salmon and ecosystem indicator series

The full long-format indicator file links brood year, source stock label, indicator and value. The abbreviation lookup is pinned as documentation. The deposit also provides stock-specific files. Units and interpretation depend on the indicator.

Stuart Munsch published version 1 under CC BY 4.0. When sharing these data, credit the creators, link the license and identify any changes. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.32086272.v1) · [Version metadata](https://api.figshare.com/v2/articles/32086272/versions/1) · [License](https://creativecommons.org/licenses/by/4.0/)

The selected source contains 5,685 rows and 4 selected fields. The package adds a one-based row number for source lookup. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
