# Juvenile steelhead counts from Idaho stream snorkel surveys

Idaho Department of Fish and Game snorkel surveys supply the juvenile steelhead counts used in this study of elevation, stream temperature and flow. This package retains the count file and its environmental covariates. The separate fish size resource and analysis scripts remain in the deposit.

Ryan Vosbigian, Alexa Ballinger, Timothy E. Link, Timothy Copeland, Matthew R. Falcy published version 1 under CC BY 4.0. When sharing these data, credit the creators, link the license and identify any changes. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.28216205.v1) · [Version metadata](https://api.figshare.com/v2/articles/28216205/versions/1) · [License](https://creativecommons.org/licenses/by/4.0/)

The selected source contains 5,226 rows and 28 selected fields. The package adds a one-based row number for source lookup. Unnamed or repeated headers receive positional aliases. Original column labels and order remain traceable to the pinned file. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
