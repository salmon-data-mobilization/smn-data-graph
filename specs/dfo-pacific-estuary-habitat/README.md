# Pacific estuaries, salmon habitat and human activities

The two English tables describe ecological attributes and human activities at 439 estuaries across the Pacific Region. The ecological file includes salmon biomass, salmon species richness and a Conservation Unit field. The activity file contains salmon gillnet, seine and troll fishery fields alongside other pressures. The estuary ID identifies rows within both pinned resources. These are compiled estuary-level features; the two tables have different field sets and both include the same 439 estuaries. The source dictionary gives units and the definitions behind the indicators. [DFO catalogue record](https://open.canada.ca/data/en/dataset/e2a6cfd7-64a3-4588-beb2-aa9c63adc9f4)
