# Commercial salmon permit earnings by residency

The selected table gives inflation-adjusted permit earnings by fishing region, year and residency group. The author expresses earnings in millions of 2017 US dollars using the Anchorage consumer price index. [KNB dataset](https://knb.ecoinformatics.org/view/doi:10.5063/F1WW7FZ2)

| Package table | Records | Original fields | Local record key |
| --- | ---: | ---: | --- |
| earnings | 2646 | 4 | Year, Fishing_region, type |

The package includes the complete regional earnings table. Supporting lookup tables, processing code and figures from the archive are outside this selection. Fishing region describes where harvest occurred. The residency categories refer to permit holders.
