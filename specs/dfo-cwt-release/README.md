# Pacific Canadian coded-wire-tag release groups

The complete DFO release file describes tagged release groups and untagged or unassociated groups. The source-local tag code or release ID is distinct and nonempty in these bytes. The dictionary describes release dates, tag types, numbers marked and release locations. Leading zeros and spaces inside source codes carry through as text. Unknown or incomplete dates remain as supplied. A release record supplies evidence about a release group. Recovery and survival require other data. [DFO catalogue record](https://open.canada.ca/data/en/dataset/09f0e153-4573-4e5d-9ba3-fd0238b4bb7a)
