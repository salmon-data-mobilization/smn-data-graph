# Mean annual salmon abundance by Alaska region

The deposited table gives means for 65 region and species combinations across 2000–2015. The authors combined escapement and fishery harvest within each year and averaged the resulting counts. [KNB dataset](https://knb.ecoinformatics.org/view/doi:10.5063/QV3JZW)

| Package table | Records | Original fields | Local record key |
| --- | ---: | ---: | --- |
| abundance | 65 | 3 | SASAP.Region, Species |

Regional attribution follows where a fish was harvested or observed escaping. This matters when a fish originates outside the region where it was caught. Each output value summarizes the entire period.

The selected DataONE metadata object is `doi:10.5063/QV3JZW`. The EML contains `doi:10.5063/F1BR8QG4` as its internal package identifier. DataONE lists that identifier as the preceding revision. [System metadata](https://cn.dataone.org/cn/v2/meta/doi:10.5063/QV3JZW)
