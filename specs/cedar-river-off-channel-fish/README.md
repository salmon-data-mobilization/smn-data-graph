# Juvenile salmonids in lower Cedar River off-channel habitats

King County scientists surveyed juvenile fish by nighttime snorkeling in spring 2023. The selected table records fish observations by transect, pass, species and size class. Wood, physical habitat, snorkel-unit and spatial files are available in the deposit.

The King County Water and Land Resources Division conducted the study with support from the Puget Sound Partnership and King County. [Study methods](https://doi.org/10.1002/nafm.11061)

Aaron David, Rebekah R. Stiling published version 2 under CC0. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.25242403.v2) · [Version metadata](https://api.figshare.com/v2/articles/25242403/versions/2) · [License](https://creativecommons.org/publicdomain/zero/1.0/)

The selected source contains 662 rows and 17 selected fields. The package adds a one-based row number for source lookup. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
