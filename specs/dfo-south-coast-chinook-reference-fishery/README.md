# South Coast BC Chinook Reference Fishery biological samples

The English resource for each of 2023, 2024 and 2025 records fish sampled in the Chinook Reference Fishery. Rows include date, creel sub-area, fin-clip status, length, size class, stock-region assignment and ranked alternatives with probabilities. The three distinct files retain the date formats used in each source. These are biological samples from a mark-selective fishery monitoring program. A ranked stock assignment is accompanied by a probability. The graph catalogues the assignment columns and leaves population identity open. [DFO catalogue record](https://open.canada.ca/data/en/dataset/61c8c2cd-ca46-457f-aaf2-052d20e1622d)
