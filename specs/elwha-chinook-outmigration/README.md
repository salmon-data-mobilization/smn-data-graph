# Elwha River juvenile Chinook outmigration at rotary screw traps

The source ZIP contains Data/outMigrantDat.csv, the daily outmigration file for the Elwha River trap study. This package retains all rows and the original five fields, including the study estimates of fish passage. Temperature, length, redd and appendix resources remain in the original ZIP.

The authors credit the Lower Elwha Klallam Tribe as a data-collection partner and a funder of collection and analysis. The collaboration also involved federal and state agencies, Clallam County Streamkeepers and Seattle University. [Study funding and acknowledgments](https://doi.org/10.3389/fevo.2023.1240987)

The selected source contains 2,352 rows and 5 selected fields. The package adds a one-based row number for source lookup. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
