# Adult steelhead length and age at Lower Granite Dam

The Lower Granite adult trap series covers 2008 through 2019. It records capture date, last ocean year, fork length reported in millimetres, saltwater age, sex and genetic stock. The separate pink salmon abundance series and analysis scripts remain in the deposit.

The deposited README credits a Bonneville Power Administration grant to the Idaho Department of Fish and Game for data collection (project 1990-055-00).

Ryan Vosbigian, Logan Wendling, Timothy Copeland, Matthew R. Falcy published version 2 under CC BY 4.0. When sharing these data, credit the creators, link the license and identify any changes. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.23233604.v2) · [Version metadata](https://api.figshare.com/v2/articles/23233604/versions/2) · [License](https://creativecommons.org/licenses/by/4.0/)

The selected source contains 27,259 rows and 7 selected fields. The package adds a one-based row number for source lookup. Unnamed or repeated headers receive positional aliases. Original column labels and order remain traceable to the pinned file. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
