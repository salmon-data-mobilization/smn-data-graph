# Fraser River mean discharge at Hope

The complete English table has two discharge series for 1912–1999. The annual series averages January–December. The flow-year series runs from April to the following March. Both use cubic metres per second. DFO describes this series as an environmental covariate studied alongside Pacific salmon production. This package contains measured river flow. The fish production indices referred to in the catalogue abstract are outside the selected table. [DFO catalogue record](https://open.canada.ca/data/en/dataset/6e97f406-c893-431a-96d3-3976490dd7bb)
