# Snake River spring/summer Chinook spawner estimates from PIT detections

The Nez Perce Tribe contributed the estimates in `ICSRSSchinookModel.csv` to the Northwest Fisheries Science Center viability report compilation. Mari Williams compiled the file for VRData 2.3. The table manual defines the method code `Model` as DABOM expansion from PIT-tag data, and the row citations identify natural-origin spawner abundance. These are modeled abundance estimates. [Pinned CSV](https://github.com/nwfsc-math-bio/VRData/blob/1511807c895c5adfd1b146a92023a9f93bffde31/data-raw/ICSRSSchinookModel.csv) · [Table manual and citations](https://github.com/nwfsc-math-bio/VRData/blob/1511807c895c5adfd1b146a92023a9f93bffde31/man/Salmon-Chinook-Snake-River-spring-summer-run-ESU-ICSRSSchinookModel.Rd)

The CSV has 159 population-year rows, 19 fields, 20 native population codes and five major population groups. Years range from 2010 through 2019, with different start years across populations. The `NMFS_POPID` and `YEAR` pair is unique within the file. All 159 rows retain the source `FRACWILD` value of `1`, the `CATCH` token `-99`, and empty `RUN_TIMING` and `LINE_NOTES` cells. The ESU label supplies the spring/summer designation. The package keeps every source citation, code and value as text.

NOAA's package license declares CC0 1.0 for its work. Its manual and CSV identify the Nez Perce Tribe as the contributor of the underlying estimates. The materials give no separate redistribution statement for the contributed series. The Spec therefore records redistribution as unconfirmed, leaves the series license unset and retains local intake status. [NOAA package license](https://github.com/nwfsc-math-bio/VRData/blob/1511807c895c5adfd1b146a92023a9f93bffde31/LICENSE) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

The [Spec](nwfsc-snake-chinook-pit-model.yaml) pins the CSV, its manual, package description and package license to one source revision. The [shared intake workflow](../source-intake/README.md) checks the four source hashes and compares every header and every one of the 3,021 data cells in the built `sdp/data/snake_chinook_model.csv` with the publisher file in order. The graph describes the table and fields. The numeric observation and cross-source identity declarations are empty.
