# Feeding and energetics of juvenile fall-run Chinook salmon

Juvenile fall-run Chinook from Coleman National Fish Hatchery in California were studied under different water temperatures. This package covers the fish-level source table with lengths, body and meal weights, temperature and experimental fields. Individual metabolism traces and R code remain in the record. The study methods are available in the [associated paper](https://doi.org/10.1093/conphys/coac067).

Vanessa Lo published version 3 under CC0. The Spec records the DOI, publisher file links, SHA-256 hashes and attribution for this deposit. [Dataset](https://doi.org/10.6084/m9.figshare.20422302.v3) · [Version metadata](https://api.figshare.com/v2/articles/20422302/versions/3) · [License](https://creativecommons.org/publicdomain/zero/1.0/)

The selected source contains 67 rows and 16 selected fields. The package adds a one-based row number for source lookup. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
