# Chinook salmon radio-tracking detections from the CTUIR study

The Confederated Tribes of the Umatilla Indian Reservation collected the radio-tracking data. The complete detection table includes fish identifiers, dates, river positions, body measurements and environmental covariates. The record credits Casey Justice of the Columbia River Inter-Tribal Fish Commission for the water-temperature inputs. Other covariate files, figures and analysis scripts remain in the deposit.

The authors obtained the remaining environmental covariates from the public repositories cited in their manuscript. The license below is the one Tara Blackman recorded on Figshare.

Tara Blackman published version 2 under CC BY 4.0. When sharing these data, credit the creators, link the license and identify any changes. The selected source contains 720 rows and 74 selected fields. The package adds a one-based row number for source lookup. The [shared replay](../source-intake/README.md) checks the built table against the publisher file. Field values remain lexical and the package declares no cross-source identities or numeric observations.
